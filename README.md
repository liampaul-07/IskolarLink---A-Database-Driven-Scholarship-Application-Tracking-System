# IskolarLink

A scholarship application tracking system with a staff interface and a public status lookup.

## Requirements
- Node.js (LTS)
- MySQL

## Setup
1. Clone the repo and run `npm install`
2. Copy `.env.example` to `.env` and fill in your MySQL credentials
3. Create the database and run `database/schema.sql`, then `database/seed.sql`
4. Start the server with `npm run dev`
